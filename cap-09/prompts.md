# Capitolo 9 — Agents

## 🔁 Sketch di un nuovo agent

```
Voglio un agent per [descrizione del task].

Persona: [es. senior TypeScript code reviewer, data scientist SaaS]
Input: [cosa riceve l'agent, es. un file controller, un dataset CSV]
Output format: [es. report strutturato con findings ordinati per gravità]
Tools allowed: [es. Read, Grep — solo lettura]
Modello: [sonnet / opus / haiku]
Scope: [progetto / utente]

Crea l'agent in .claude/agents/ (o ~/.claude/agents/ se utente).
```

Sostituisci le parti tra parentesi quadre e incolla il prompt in Claude Code. Ottieni il file dell'agent pronto da rivedere.
