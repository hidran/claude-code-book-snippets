## Cos'è questo repo

Questo repository raccoglie tutto il materiale copia-incollabile del libro:

- **19 prompt riusabili** estratti dai 16 capitoli, ognuno con `[PLACEHOLDER]` da sostituire con il tuo progetto
- **50 prompt categorizzati** nell'Appendice C — la cheatsheet completa per uso quotidiano
- Punto di riferimento per chi vuole applicare il workflow del libro ai propri progetti senza riaprire il PDF

## Prompt Cheatsheet

Il file [`prompt-cheatsheet.md`](prompt-cheatsheet.md) è la versione testo puro dell'**Appendice C** del libro: 50 prompt copia-incollabili divisi in 10 categorie — pensati per uso quotidiano senza dover riaprire il libro.

Categorie: Esplorazione progetto · Pianificazione/Plan Mode · Refactoring · Bug fix · Test · Code Review · Documentazione · DevOps/Deploy · Security · Refactoring DB

## Come usarlo

1. Apri il file del capitolo che stai leggendo
2. Copia il prompt
3. Sostituisci i `[PLACEHOLDER]` con i dettagli del tuo progetto
4. Incolla in Claude Code

## Il libro

📖 **[Claude Code: la guida pratica](https://www.amazon.it/Claude-Code-vibecoding-Development-Dallinstallazione/dp/B0H26H662N)** — disponibile su Amazon Kindle

Il primo libro italiano completo su Claude Code: dall'installazione al deploy AWS di un progetto full-stack reale (NestJS + React + MySQL + S3 + CloudFront). Copre skills, agents, Spec Driven Development, code review multi-LLM (Claude, Gemini, Codex, Kimi) e workflow professionale per sviluppatori intermedi. ~390 pagine.
