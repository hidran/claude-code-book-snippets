## Come usarlo

Ogni file `prompts.md` contiene i prompt marcati 🔁 nel capitolo corrispondente.
Sostituisci i `[PLACEHOLDER]` con i valori del tuo progetto.

Per errori o suggerimenti: [issues](https://github.com/hidran/claude-code-book-snippets/issues) con tag `errata`.
